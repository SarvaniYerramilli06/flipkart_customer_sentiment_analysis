# flipkart_customer_sentiment_analysis
Exploratory data analysis and sentiment analysis of Flipkart product reviews using Python and TextBlob.
# Customer Sentiment Analysis on Flipkart Product Reviews

This project analyzes customer reviews of Flipkart products to understand customer sentiment, rating patterns, and feedback trends using Python.

Completed as part of my **Data Analytics Internship with LaunchedGlobal**, the project combines exploratory data analysis (EDA), text preprocessing, sentiment classification, and data visualization.

# The Objectives of this Project:

* Clean and preprocess customer review data.
* Analyze customer ratings and review patterns.
* Classify reviews as positive, neutral, or negative.
* Visualize sentiment distribution and frequently used words.
* Derive insights into customer satisfaction.

## Dataset

The dataset contains approximately **2,304 customer reviews**. Missing values, duplicate records, and unnecessary columns were checked during data cleaning.

## Tools & Technologies

* Python
* Pandas and NumPy
* Matplotlib and Seaborn
* TextBlob
* WordCloud
* Google Colab

## Methodology

1. **Data Cleaning:** Checked missing values, duplicates, and unnecessary columns.
2. **Exploratory Data Analysis:** Examined rating distribution, review length, product review counts, and correlations.
3. **Sentiment Analysis:** Used TextBlob polarity scores to classify reviews as positive, neutral, or negative.
4. **Visualization:** Created charts and word clouds to communicate findings.
